# Practica 4 - Bootstrap y SASS

Tienda de ordenadores (PCStore) hecha con Bootstrap 5.3 y SASS.

## Paginas

- `index.html` - inicio con carrusel, categorias, destacados, video y contacto
- `catalogo.html` - catalogo con buscador y filtro por categoria
- `detalle.html` - detalle de producto con pestanas
- `novedades.html` - tienda de los nuevos productos (Serie 2026)
- `lanzamiento.html` - detalle del nuevo producto
- `login.html` y `registro.html` - inicio de sesion y registro
- `carrito.html` y `pago.html` - carrito y pago

## Compilar el CSS

```
npm install
npm run build:css
```

Genera un unico fichero `css/style.css` a partir de `scss/main.scss`.
